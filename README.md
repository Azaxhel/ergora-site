# Landing Institucional Ergora

Landing institucional pública da Ergora Automações, alinhada à identidade visual mínima Ergora Carbon.

## Status

Publicada em `https://www.ergora.com.br/`.

Este diretório é o candidato atual a clone canônico da landing publicada. Existe uma cópia local mais antiga em `02_mercado_marketing/landing_ergora`, que deve ser preservada até a consolidação formal dos clones.

## Objetivo

Apresentar a Ergora como uma empresa de automação para rotinas administrativas, relatórios operacionais e organização de processos.
